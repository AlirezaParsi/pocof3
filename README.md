## 📌 **Features**

✨ **Performance Enhancements**  
- Optimized CPU governors and I/O schedulers for smoother performance.
- Improved memory management for faster app launches.

🔋 **Battery Optimization**  
- Advanced power-saving tweaks for longer battery life.
- Wakelock blockers to reduce unnecessary battery drain.

🔒 **Security**  
- Built with the latest security patches and hardening features.
- SELinux and AppArmor support for enhanced protection.

⚙️ **Customization**  
- Support for KernelSU Next and other root solutions.
- Customizable kernel parameters for advanced users.

🚀 **Cutting-Edge Technology**  
- Built with the latest Clang toolchain for optimized performance.
- Support for SUSFS and other modern filesystems.

## 📥 **Installation**

### Prerequisites
- Unlocked bootloader.
- Custom recovery (e.g., TWRP) installed.
- Backup your data (just in case).

### Steps
1. Download the latest N0Kernel zip file from the [Releases](https://github.com/AlirezaParsi/pocof3/releases) section.
2. Boot into recovery mode.
3. Flash the N0Kernel zip file.
4. Wipe cache and Dalvik cache (optional but recommended).
5. Reboot and enjoy!
